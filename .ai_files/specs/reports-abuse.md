# Spec: Reports / Abuse Handling

## Problem Statement
Users report problematic listings; staff resolve reports from the dashboard.

## User Stories
1. As a logged-in user, I want to report an approved site once.
2. As staff, I want to resolve a report via AJAX.

## In Scope
- `report_website`, `resolve_report_ajax`, Report model

## Out of Scope
- Automated takedown
